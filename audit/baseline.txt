  src/widgets/_shared/buttonIcons.tsx(101,44): error TS2503: Cannot find namespace 'JSX'.

Cause : `type IconComponent = (props: IconProps) => JSX.Element`
  → En React 19 avec `"jsx": "react-jsx"`, le namespace global `JSX`
    n'est plus disponible. Il faut utiliser `React.JSX.Element` ou
    `React.ReactElement`.

Note : `tsc --noEmit` (sans -b) passe sans erreur. La divergence vient
  du fait que `tsc -b` traite les project references et les build infos
  de manière différente. Le build de production est donc cassé à la
  baseline.
